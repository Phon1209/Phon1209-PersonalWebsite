I was wondering for a long time ever since I learned that most performance-critical library in python is written in C or C++. Like how does that even work?

So, today I just learned that in interpreter, we are not running the code, we are running the interpreter that read the code as a data and adapt the functionality depending on the data read unlike the compiled program that translated into machine code.

This also implies that interpreter itself is just the compiled program that read the code which open a lot of possibility of interlink multiple programming language together.
