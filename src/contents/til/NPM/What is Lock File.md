With just `package.json` file, it only asks for major/minor version and up but not the exact version. This can result in conflicting dependencies when peer dependencies are requesting different major version. So even if we do `npm i` with the same `package.json`, we could probably get a different group of dependencies version. `package-lock.json` will help save the exact version of the installed packages, and we can use `npm ci` to install the exact dependencies.
